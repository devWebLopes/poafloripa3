# Poa Floripa Imóveis — Edição Minimalista (Deploy Vercel)

Aplicação web minimalista inspirada em `fernandasardaimoveis.com.br`, mantendo a paleta Azul Piscina (`#00B4D8`) + Azul Oceânico Secundário (`#007791`) e os efeitos visuais (imagens em movimento, itens flutuantes, scroll atrasado e hover elegante).

## Como publicar na Vercel
1. Extraia o arquivo `poa_floripa_vercel_deploy.zip`.
2. Suba a pasta na [Vercel](https://vercel.com/new) ou execute `npx vercel --prod`.

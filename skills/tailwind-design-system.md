# Skill: tailwind-design-system

**Objetivo:** aplicar a identidade visual sem quebrar os efeitos.

## Regras
- Usar tokens do `tailwind.config` (`pool`, `minimal`, `brand`).
- Tipografia: `font-serif` para títulos, `font-sans` para UI.
- Efeitos assinatura: `.motion-canvas`, `.architectural-float`, `.lag-item`, `.sarda-card`, `.auxiliadora-mosaic`.
- Adicionar `@media (prefers-reduced-motion: reduce)` desativando animações.
- Estilo minimalista: bordas `#EAEAEA`, sombras suaves.
